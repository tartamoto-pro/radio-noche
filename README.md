# Radio Noche

App Android para escuchar El Partidazo de COPE y Tiempo de Juego desde el principio aunque te acuestes tarde.

- Graba sola la emisora a la hora fijada (por defecto L-V 23:30–01:30, S-D 22:00–01:30).
- "Desde el principio": reproduce la grabación mientras se sigue grabando.
- Directo, ±30 s, seguir donde ibas y temporizador para apagarse.

**Descargar:** https://github.com/tartamoto-pro/radio-noche/releases/download/ultima/RadioNoche.apk

Cada cambio en `main` vuelve a compilar el APK con GitHub Actions.
